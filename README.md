# Omaha Lancers Chapel

Editable React/Vite frontend for the Omaha Lancers Chapel app.

Key app behaviors:
- Daily check-in is based on the America/Chicago calendar day; history/streak is preserved.
- Team Chat supports one like per user and admin deletion.
- Private messages live under Chat → Messages and are restricted to Pastor Ryan ↔ player.
- Web push registration supports Pastor Ryan messages, chapel schedule notifications, and check-in reminders.
- Pregame prayer RSVP is shown for home games, five games at a time.

Backend data and notifications are provided by the existing Lancer Chapel Supabase project.
